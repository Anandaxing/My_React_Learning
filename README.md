# Documentation

## Article component 

This article component is where I learned about useCallback method, used for stopping unnecessary function rendering within the client react component unless a variable it respects to is changed.

## Jumbtron component

This is a component where I learned about useMemo, meaning that it prevents overwhemling calculations done by the functions by storing it in a cache and only be re-rendered once a variable it respects to is changed.
